# Генератор дек вебинаров родительской линейки (№02–12)

Питон-инструмент, которым собраны деки `design/webinars/parent-02…12/` по скелету №01.

## Запуск

```bash
python3 scripts/deckgen/gen.py
```

Пишет `index.html` и `art.css` в каждый `parent-NN/`. Вывод byte-identical при неизменных данных.

## Что где лежит

- `weeks_data.py` — весь контент 11 выпусков: титул, компетенция, навыки, пять дней, наука (привязка к `content/webinars/SOURCES.md`), три ошибки, три дела, вопрос за ужином, мини-кейс, FAQ, «что в руки», символ.
- `gen.py` — шаблон HTML (23 слайда) и рендер.
- `shared/` (вебарт, шрифты, deck.css/deck.js) — в `design/webinars/shared/`, не генерируется.

## Правила

- Правки контента `parent/NN-*.md` нужно зеркалить здесь (`weeks_data.py`) — деки собраны из данных, не из .md напрямую.
- Регенерация перезаписывает `index.html` и `art.css` — ручные правки в них будут потеряны. Правим данные, не вывод.
- Цифры в науке — только по `content/webinars/SOURCES.md` (S1–S10). Без строки в SOURCES.md — без цифр.
- Мини-кейсы — «смоделированный, но типичный», герои вымышлены.
