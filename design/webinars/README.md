# Серия вебинаров «Гиб · Открытая мастерская» — родительская линейка

12 выпусков по 23 слайда, код (не самопал-растр): PT Serif + Inter, бумага/чернила/латунь, стиль «Занавес».

## Открыть

```bash
cd design/webinars && python3 -m http.server 8080
# http://localhost:8080/parent-01/ … /parent-12/
```

или `open parent-02/index.html`. Клавиши: `←/→` — слайды, `S` — заметки ведущего, `F` — во весь экран, `⌘P` — печать.

## Что где

- `parent-01/` — выпуск №01 «Кто я и что я чувствую», эталон (стоит отдельно, самодостаточен).
- `parent-02/…parent-12/` — выпуски №02–12. Каждый: `index.html`, `art.css` (фон-занавес), `assets/` (герой/символ/«что в руки», без людей).
- `shared/` — общее для №02+: `deck.css` (сцена «Занавес»), `deck.js` (навигация, счётчики, донат 48 навыков), `fonts/` (self-hosted Inter + PT Serif), `img/` (окна линеек Лис/Мира/Тима).
- `ART-BRIEFS.md` — арт-дирекшн серии: сцена по неделям, промпты, статусы.
- `scripts/deckgen/` — генератор дек №02–12 (регенерация из `weeks_data.py`).

## Правки

- Контент: `content/webinars/parent/NN-*.md` (и `.full.md`) → зеркалить в `scripts/deckgen/weeks_data.py` → `python3 scripts/deckgen/gen.py`.
- Цифры: только из `content/webinars/SOURCES.md`. Мини-кейсы — «смоделированный, но типичный».
- `.md ↔ .full.md` зеркалить генераторам (`gen-lesson-webinars.ts`, `expand-webinars.ts`) при регенерации текстов.
- `out/` — рендеры и контакт-листы, не коммитится.

## Печать

`⌘P` печатает текущий слайд/деку; ART-фон тяжёлый и яркий на белом — см. открытый вопрос владельцу про `@media print`.
