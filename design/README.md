# Концепт дизайна: 3D-персонажи и единый язык экосистемы

Это не продукт и не финальный арт, а **согласованный на 16.11.2026 черновик направления**.
Макет `preview/index.html` собран, чтобы обсуждать язык на настоящих экранах, а не на словах.

## Что решено

| Вопрос | Решение |
|---|---|
| Стиль персонажей | **Мягкий объём**: плотная, но мягкая фактура (фетр, ткань, потёртая кожа), студийный свет сверху, крупные глаза с блик­ом. Не глянцевый пластик и не «мультсериал 90-х» |
| Маскоты | **Каст из трёх проводников** по возрастным линейкам: Лис (5–7), Мира (8–10), Тима (11–13) |
| Навыки | **6 существ навыков** (внимание, память, гибкость, торможение, планирование, логика) — не по персонажу на каждый пункт программы |
| Компетенции | **7 мест района** (мастерская, двор, библиотека, площадка…), а не 7 новых зверей |
| Личное | **Один питомец** на ребёнка: он и есть уникальность, а не 23 маскота в продукте |
| Регистры | Один язык в трёх плотностях: **игра** (ребёнок), **кабинет** (родитель, педагог), **документ** (оферта, юридика, школа) |

## Что лежит в папке

- `3d/lis.png`, `3d/mira.png`, `3d/tima.png` — выбранные пробы стиля (сгенерированы, не финальный арт);
- `preview/index.html` — макет экосистемы: детский экран, три линейки, кабинет родителя, правила стиля;
- `preview/img/` — кропы персонажей для макета;
- `preview/preview.png` — полная страница макета картинкой.

Тексты и числа в макете **взяты из кода**: день 2 «Задание Миры» (тема «Я и другие», 8–10 лет,
три варианта с подсказками), 36 встреч по 40 минут, 60 дней, 12 тем и показов.

## Как открыть

```bash
cd design/preview && python3 -m http.server 3100 --bind 0.0.0.0
# затем http://localhost:3100/index.html
```

## Палитра и правила

- чернила `#241D31`, бумага `#FDF4E9`, награда `#F2B544`;
- акцент героя: Лис `#EC6F38`, Мира `#2E9E80`, Тима `#5A68C6`;
- **один акцент на экран**, не больше;
- силуэт героя читается в 24 px: разные формы головы (остроконечная / круглая / угловатая) и предмет-подпись
  (хвост-кисть, рюкзак и блокнот, наушники и планшет);
- **не делаем**: белые перчатки и глянцевый пластик (читается как чужая франшиза), тени-наклейки
  в кабинете и документах, новых зверей на каждый пункт программы.

## Чего в этом черновике ещё нет

1. **Паспорта стиля** — пропорции, ракурсы, обязательные позы (стоит, слушает, думает, радуется), hex-таблица.
   Сейчас есть три пробы и правила, но не библия персонажей.
2. **Существ навыков и питомца** в той же фактуре.
3. **Согласованности каста**: три картинки сделаны отдельно, у них разный свет и разная детализация.
   Для продукта нужен один стиль-гайд и одна серия отрисовки, иначе герои «из разных мультфильмов».
4. **Проверки в коде**: макет статический. Перенос в приложение — отдельная работа с токенами
   (`lib/design/tokens.ts`), контрактом ассетов и тестом на расхождение палитры.
