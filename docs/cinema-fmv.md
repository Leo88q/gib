## 0. Действующий превиз (текущий этап)

AI-референсы 2D отброшены: они не дают согласованный «полноценный 3D с любого ракурса». Вместо них — настоящий 3D-превиз без Blender (software render, numpy+Pillow):

```bash
python3 -m venv .venv-3d && .venv-3d/bin/pip install numpy pillow
.venv-3d/bin/python scripts/previz-theatre-class.py
# → design/3d/preview/previz-class-{A,B,D,Av}.png
```

Что это: зафиксированная геометрия (комната 9×11 м, «чёрный кабинет» — тёмные стены, паркет, мини-сцена с шагами, занавес вишнёвый с волной, латунная арка просцениума, рампа из 7 янтарных огней, торшер, ковёр — акцент Миры, камеры A≈130 см / B три четверти / D высокая 45° / Av вертикальная 9:16). Это **блок-аут**, не финальный лук: пропорции и состав согласовываем по нему, потом тот же файл геометрии переносится в Blender-сборщик (§8, этап 2) с материалами «мягкого объёма» и Eevee/Cycles.

Рендеры `previz-class-*.png` — в репозитории (`design/3d/preview/`); `.venv-3d/` игнорируется.

Параллельно собрана интерактивная look-dev песочница **«Студия «Дубль»** — `design/studio-sandbox/index.html` (three.js локально, 0 ₽): 7 планов + тележка, 2 световых состояния «репетиция⇄выступаем» + поштучные прожекторы, **занавес (открывается/закрывается)**, кассеты (Дом/Мастерская/Библиотека), экран-арка, «Паспорт сцен», хлопушка «ДУБЛЬ N» + чип в шапке (клавиша `D`). Это **не часть приложения** и не замена Blender-этапу — стенд для механик и пропорций.

## 1. Что такое «золотой эпизод»

День 1 программы, линейка 8–10, **все три входа**: `w1d1` (поделку смяли — Мира), `w1d1_music` (репетиция — Тима), `w1d1_picture` (рисунок на выставке — Мира). Каждый вход — двухуровневое дерево из `content/ink/deep/`: вход → 3 первых выбора → по 2 вторых у каждого → 6 концовок.

| Вход | Файл | Первые | Вторые | Концовок |
|---|---|---|---|---|
| `w1d1` | `content/ink/deep/w1d1-8-10.ink` | 3 | 2+2+2 | 6 |
| `w1d1_music` | `content/ink/deep/w1d1_music-8-10.ink` | 2* | 2×2 | 4 |
| `w1d1_picture` | `content/ink/deep/w1d1_picture-8-10.ink` | 2* | 2×2 | 4 |

*Тексты используются как есть; менять смысл без «go» нельзя. Раскадровки `data/storyboards.json` для w1d1 упоминают Тиму, хотя текст — про Миру, — расхождение пометить на методистскую вычитку; при сборке эпизода истина — текст.

**Готовый материал по сценарию симулятора (в репозитории):** `content/ink/**` — 452 ink-сцены (42 week-one + 375 remaining + 33 deep + garden/rumor); раскадровки `data/storyboards.json` — **121 сцена × 3 линейки = 363 раскадровки, 919 кадров** (план/ракурс/действие/эмоция/секунды/камера); постановка `data/art-shotlist.json` — 121 сцена. ink — канон; раскадровки и shotlist — постановочный слой поверх него.

Результат — не «фильм», а **плейлист-библиотека**: плейты сета + биты Миры + биты Златы; новый узел любого из входов собирается регистрацией сегментов в манифесте, без единого нового рендера.

Оба формата: рендер мастером под 16:9 с безопасным кропом 9:16 (либо съёмка на две камеры — решается на площадке).

## 2. Зафиксированные решения

- Сет «Театральный класс» — **ручная сборка в Blender** (см. `docs/studio-hybrid.md`); готовые модели — только визуальный референс; ТВ/вебинарные студии не берём.
- **Биты, не ветки**: никаких уникальных клипов на развилку; сцены = плейлист сегментов.
- **Злата — рамка**: вход (постановка задачи) → пауза (вопрос без ответа) → выход (рефлексия). Внутри сцены играют персонажи; выбор делает ребёнок. Это защищает от «подсказчика» — педагог говорит рамку, опыт остаётся ребёнку.
- **Реплей из точки паузы** — бесплатен, сервер не трогаем; награда прежняя (решение владельца).
- **Липсинка нет**: реплики — голосом Златы, пантомима персонажей; субтитры обязательны на всех битах Златы.
- **Кейинг офлайн** (Resolve / Blender Compositor); в реальном времени — только OBS-превью.
- **Альфа-порядок**: HEVC-alpha (.mov) → VP9-alpha (.webm) → mp4-заглушка. Выбор по `canPlayType`; «alpha-pack H.264 + WebGL» — оптимизация фазы 2, **не пилот**.
- **Платформа (28.11.2026)**: **MAX Mini App и VK Mini App**, не Telegram; Telegram-путь — легаси, код не удалён до отдельного решения (`docs/decisions.md`). WKWebView-чеклист заменяется на MAX WebView и VK WebView; `telegram-web-app.js` → MAX Bridge / VK Bridge (или нейтральные фолбэки). ВК-мост ещё не реализован — до его появления QA по VK отсутствует.
- **Занавес (28.11.2026)**: «репетиция» — приоткрыт, «выступаем» и «Премьера» — открыт; в песочнице — кнопкой «Занавес» и мастер-светом. В Blender-сборке — морф панелей занавеса, рендерится в кадр.
- **Счётчик дублей — везде (28.11.2026)**: «ДУБЛЬ N» на хлопушке на столике + чип в шапке (look-dev: клавиша `D`, кнопка «Новый дубль»); в продукте — из `story_takes.takeNo` после обновления текстов приватности (`docs/dubble.md` §7–8). Дубль не даёт оценок и не меняет награды за первый проход.
- **Пресет `scene` в манифесте v2 (28.11.2026)**: см. §3 — «режиссура кадра» декларативно, fail-soft.
- **Проигрыватель**: расширение CinemaStory; флаг `NEXT_PUBLIC_CINEMA_STORY=1` как есть; `prefers-reduced-motion` → текстовый режим; любой сбой → ScenarioView.
- **Голос**: Злата Бабенко; любые TTS — отменены.

### Пресет `scene` (28.11.2026, реализовано)

У сегмента может быть опциональное поле `scene` — «режиссура кадра». Её потребляет либо офлайн-сборщик (Blender: занавес/кассеты/свет рендерятся в кадр; пресет остаётся метаданными для редактора и QA), либо реалтайм-плеер (Eevee/WebGL). Все поля опциональны; неизвестные значения отбрасываются молча (fail-soft), сегмент при этом сохраняется:

```jsonc
{ "id": "mira-hope", "layer": "character",
  "src": { "vp9": "/…/mira-hope.webm" },
  "scene": {
    "camera": "closeMira",     // hall|stage|threeQuarter|top|closeLis|closeTima|closeMira|dolly
    "light": "rehearsal",      // rehearsal|show  (мастер «репетиция⇄выступаем»)
    "curtain": "half",         // half|open
    "cassettes": "none",       // none|dom|workshop|library
    "screen": "hidden",        // hidden|slides|repertoire
    "lightsOn": ["spotC"],     // досвет к мастеру: spotL|spotC|spotR|ramp|floorLamp|window|screen
    "heroes": { "mira": "thinking" }  // lis|tima|mira → calm|loud|sad|relief|thinking
  } }
```

Идентификаторы камер совпадают с кнопками песочницы `design/studio-sandbox/` (hall=Зал, stage=Сцена, threeQuarter=Три четверти, top=Сверху, closeLis/closeTima/closeMira=Крупные, dolly=Тележка) и дополняют «план/ракурс» раскадровки `data/storyboards.json`. Порядок досвета фиксируется `FMV_LIGHT_ORDER`. Тесты: **23 проверки**, `npm run test:cinema-manifest-v2` — все зелёные.

Слои (z-order снизу вверх, сортировка детерминированная): `set → character → zlata → window`.
Правила нормализации (fail-soft, как в v1): ключ как в v1; сегмент без единого пути (`/…`) отбрасывается; дубликаты id — первый выигрывает; запись без валидных сегментов отбрасывается; `replayFrom` на несуществующий сегмент обнуляется. `pickFmvSource(src, canPlay)` — hevc → vp9 → mp4.
Субтитры: по файлу `<segment-id>.vtt` рядом с сегментом (условность монтажа); плеер подключает `<track kind="subtitles">`; для 9:16 допускается burn-in.

`npm run test:cinema-manifest-v2` — 17 проверок, все зелёные; v1 не тронут (`CinemaStory.tsx` — следующий этап с отдельным ревью: сегментный плеер + `canPlayType` + кнопка «переиграть сцену» + скрытые `<track>`).

## 4. Биты золотого эпизода (минимум для дня 1, 8–10)

**Сет (плейты, loop):** `set-plate` — Театральный класс, ракурс A (анфас), 3–4 (три четверти), D (высокий 45°); один plate на ракурс с циклическим движением света (8–12 с).
**Персонаж (Мира):** `idle-soft` (дыхание, моргание) · `soften` (смята поделка) · `hope-tilt` (обращение взглядом) · `relief` (после поддержки) · `thoughtful` (пауза перед ответом). 5 битов × 2 крупности (средний, крупный) = 10 рендеров. Мер делать не нужно: пантомима.
**Злата (съёмочный день, 12–14 битов, 5–15 с, 3 крупности):** приветствие+рамка (`zlata-in-w1d1` / `-music` / `-picture`), нейтральная пауза ×2 (`zlata-pause-…`), рефлексия на выход с вилкой исходов (`-out-a/b`), «переиграть»-стик (`zlata-replay`), тишина-моменто. Субтитры .vtt на каждый.
**Окна:** слайды-схемы дня 1 (дека `*.full.md` → HTML-слой поверх) — не видео; экономят мегабайты и дают кириллицу без ART-артефактов.

Раскадровка под два формата: мастер-камера 16:9; 9:16 — центральный кроп (позиция Миры/Златы — по safe-зоне 9:16, проверить на превью).

## 5. Съёмочный лист (один день, Злата)

- Полотно хромакей, дистанция ≥ 1,5 м, равномерный свет фона отдельно от ведущей; ключ 45°, заполнение мягко, контровой — отделение от фона; палитра «Занавес»: тёплый ключ ~3 200–4 300 K, никаких зелёных рефлексов на коже/волосах.
- eye-line метки по линейкам: 5–7 ≈ 115 см · **8–10 ≈ 130 см** · 11–13 ≈ 150 см (или прицел «в камеру» как дубли).
- Фикс WB и экспозиция; 4K 25/30 fps; петличка; уровень −12…−6 дБ.
- Каждый бит — 2 дубля; лучшие отдать в Resolve; звук отдельной дорожкой.
- Ведёт площадку: вы (или ваш оператор); ассистент по дублям; я — чеклист и приёмка.

## 6. Чеклист композитинга (Resolve / Blender)

1. Ключ: 3D Keyer (Resolve) или ноды Keying (Blender); despill; края на движении волос → CorridorKey как план Б.
2. Цвет: единый LUT на Злате во всех битах (нейтраль); совпадение яркости с плейтом (замер LUFS/яркости плейта — держать ±0,5 ст.).
3. Экспорт на бит: `vp9.webm` (alpha, CRF ~28) + `hevc.mov` (hvc1, alpha); 9:16 и 16:9 — по файлу каждого (≈ 4 файла/бит, 8–12 МБ на 8 с).
4. Плейт сета: h264 mp4 (без альфы), 8–12 с цикл.
5. Сборка: Blender/Resolve, экран-чек на уровне глаз ребёнка.
