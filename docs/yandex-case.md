# Кейс для Яндекса: «ГИБ» — доступные гибкие навыки через актёрский тренажёр

Черновик письма/презентации для менеджера AI Studio и представителя Yandex Cloud. Перед отправкой: заполнить «Сделано» фактическими цифрами пилота и выгрузки `out/ai-grant-spend.jsonl`; числа ниже намеренно не выдуманы — всё, что помечено «после пилота», так и останется незаполненным до момента появления.

## Одна строка

«ГИБ» — детский онлайн-театр гибких навыков (5–13 лет): 60 сюжетных дней в трёх возрастных линейках, родительский кабинет, подписка 599 ₽ без автоматического продления, полное удаление данных ребёнка по нажатию.

## Почему это социально важно (тезисы, без воды)

- **Мягкие навыки не входят в школьную программу**: эмоциональное регулирование, общение, ответственность дети получают из улицы и соцсетей — часто с плохим результатом. ГИБ закрывает дефицит структурным форматом «история → выбор → последствия».
- **Доступность против цены репетитора**: групповое актёрское мастерство для города — 5 000–15 000 ₽/мес; индивидуальная секция — дороже. Подписка 599 ₽ делает методику доступной семьям с обычным доходом.
- **Семья, а не «дети против родителей»**: родителю даны отчёт недели, домашний «семейный дубль», идеи для вечера; привлечение родителя — встроенный механизм, а не маркетинг.
- **Дети без доступа к кружкам**: это цифровой формат для регионов, где нет театральных студий и детских психологов рядом с домом.
- **Безопасный продукт по конструкции**: минимум данных (ник, возраст, выборы), никакой биометрии и голоса детей в облаке, никакой рекламы и внутриигровых покупок для ребёнка, удаление данных в один шаг, документы в открытом доступе (политика/оферта/согласие), отдельный баннер и страница про cookies.

## Что уже сделано (верифицируемо по коду)

- Программа: **60 дней × 3 возраста**, три самостоятельные линейки, все исторические ветки проверены автоматически (компиляция ink, граф переходов, достижимость, полный проход SQLite HTTP с рестартами).
- **139 историй, 54 навыка**, карта навыков в репозитории (`docs/skills-map.md`).
- **3 478 автоматических проверок** в `npm test` (доступность, платежи, согласие, возврат денег, удаление данных) + сборка production.
- Правовой пакет: политика конфиденциальности, оферта, условия возврата, согласие представителя, cookies-страница; согласие требуется до создания профиля и до каждой сессии; редакции от 17.11.2026.
- Эксплуатация: SQLite/WAL + экспериментальный PostgreSQL, резервирование, мониторинг-стек (Prometheus/Alertmanager), Dockerfile, docker-compose, runbooks.
- Запуск отложен осознанно: ждём реквизиты оператора (есть), РКН-уведомление и РФ-хостинг (внешние шаги).

## Что делаем на грант (факт после запуска скриптов)

- **Озвучка всего корпуса** (SpeechKit): ≈326 тыс. символов, ≤ 500 ₽ — открыт первый канал для детей, которых читают за них.
- **Иллюстрации сцен** (Alice AI ART): неделя 1 → потом весь курс; отбраковка по человеческому критерию.
- **Ревью корпуса моделью** (Alice AI LLM Flash): сложность чтения/навыки/сигналы безопасности по каждой истории — черновик для методиста.
- Журнал расхода — построчно: `out/ai-grant-spend.jsonl`.

## Что просим

1. **Продление и/или увеличение гранта AI Studio** до запуска (ориентир: 50–100 тыс. ₽ на озвучку+арт всей программы, полные итерации и контент-конвейер «Черновик → ревью методиста → выпуск»).
2. **Уточнение покрытия**: распространяется ли грант на Managed Service for PostgreSQL и Compute (сейчас — только на AI-продукты, вероятно); если нет — расчёт минимальной конфигурации РФ-хостинга для запуска (Managed PG Smol + 1 × 2 vCPU/4 GB + Object Storage + Lockbox + Certificate Manager + Application Load Balancer) и ориентировочная цена в месяц.
3. **Техническое ревью архитектуры** перед запуском (1 встреча с инженером): Managed PG или VM+Docker, бэкапы/ретеншн, Lockbox для секретов, домен и TLS, базовая отказоустойчивость в пределах бюджета.
4. **Бренд-голос для детского контента** (Brand Voice / выделенный голос) — опция обсуждения; или доступ к Alice AI Pro на время пилота.
5. **Публикация кейса** (по нашему согласованию) после запуска и пилота: «российские генеративные модели в детском продукте» — с нашим одобрением каждого слова.

## Что готовы дать взамен

- Обезличенные цифры пилота (стоимость и качество) в открытом доступе после пилота.
- Выступление/интервью (по отдельному согласованию) о том, как российская связка Yandex Cloud + AI Studio закрыла полный цикл детского продукта от текста до голоса и арта — при условии, что обещания отражают реальность (мы не обещаем того, чего нет).

## Честные ограничения

- Это пока не «работает в школе»: пилот и полевая проверка — впереди (по согласию семей).
- Сгенерированные арт и озвучка проходят человеческий отбор и редактуру; «совсем без людей» — не наш режим.
- Юридические внешние шаги (РКН, хостинг, оплата) выполняются оператором самостоятельно — Яндекс не сторона этих отношений.
