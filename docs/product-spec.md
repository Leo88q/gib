# Продуктовая спецификация v0.1 (MVP)

---

## 1. Позиционирование в одном предложении
Программа, которая тренирует **исполнительные функции** (attention, рабочая память, гибкость, планирование) **и поведенческие навыки** (распознавание эмоций, саморегуляция, договорённости, критическое мышление) — с еженедельным отчётом родителю и поддержкой специалиста.

## 2. Пользователи и роли
- **Ребёнок (5–13 лет)** — играет, не платит, не оставляет личных данных.
- **Родитель (законный представитель)** — платит, видит отчёты, согласовывает данные (аккаунт родителя — все данные ребёнка).
- **Специалист (нейропсихолог/педагог)** — в MVP: разбор раз в месяц; в фазе 2: live-сессии и корректировка программы.

## 3. Ключевые экраны
1. Онбординг родителя (возраст, что хотим улучшить, согласие с ПД, согласие представителя на данные ребёнка).
2. Онбординг ребёнка: ник + аватар, выбор «любимого персонажа», короткий входной чек (3 задачи, 5 минут) → персональный стартовый уровень.
3. **Тренировка дня (15 мин)** — 3–5 заданий: 2 когнитивных + 1 мягко-навыковый сценарий + разбор.
4. **Карточка компетенции** — «сегодня тренируем: переключение / саморегуляция» с прогрессом.
5. **Еженедельный отчёт (для родителя)** — в Telegram-боте + PDF.
6. **Офлайн-миссия** — задание на 10–15 минут с родителем (из Harvard EF Activities, адаптированное).
7. **Профиль навыков** — радар по 8–10 навыкам + 5 мягким компетенциям, с комментарием «что тренировали и зачем».

## 4. Когнитивные задания MVP (10)
| # | Задание | Навык | Сложность адаптируется по |
|---|---|---|---|
| 1 | Dual N-back (визуал + звук), n=1..3 | рабочая память | точность + RT |
| 2 | Corsi-блоки (4–7 блоков, вперёд/назад) | пространственная рабочая память | длина序列 + ошибки |
| 3 | Цифровой ряд (вперёд/назад) | объём памяти | длина |
| 4 | Stroop (цвет слова) | торможение | доля конгруэнтных + RT |
| 5 | Flanker (стрелка/знак) | торможение, фокус | RT |
| 6 | Trail Making B (на экране: цифры↔буквы по кругу) | переключение | время + ошибки |
| 7 | Сортировка правил (правило меняется) | гибкость | % правильных смен |
| 8 | Tower of London lite (2–4 хода) | планирование | число ходов |
| 9 | Go/NoGo | импульс-контроль | false alarms |
| 10 | Правда/ложь по смыслу (последовательности) | логика + торможение | точность |

Алгоритм: staircase (2 верно подряд → сложнее, 2 неверно → проще) + «уровень навыка» 1PL/Elo для радара профиля.

## 5. Мягко-навыковые сценарии MVP (14 = 7 компетенций × 2)
Компетенции: самопознание / саморегуляция / эмпатия / отношения / решения / творческое мышление / **уверенность и ошибка** (мышление роста).

Формат каждого сценария:
1. **Ситуация** (150–250 слов + картинка, возрастной контекст РФ: двор, столовая, чат, кружок, транспорт, бабушка).
2. **Выбор/действие** ребёнка (2–4 варианта) — без «правильного» в лоб, с нюансами.
3. **Разбор**: что чувствовали участники, что произошло, какие были варианты, что попробовать в следующий раз.
4. **Связка с когнитивным заданием** (напр., «переключиться с обиды на задачу» → задание на Trail Making).
5. **Микро-задание в офлайн** (одно предложение родителю на дом).
6. **Строка в отчёте** (навык + прогресс + наблюдение).

Примеры-скелеты:
- «Друг не позвал на день рождения» → самопознание/эмпатия → разбор чувств → задание на распознавание эмоций по словам.
- «Ты сделал домашку, но брат смотрит телевизор» → решения/отношения → «своя зона ответственности» → планирование (Tower of London).
- «Ошибка в контрольной» → мышление роста → разбор «ошибка = данные» → задание на скорость с обратной связью.
- «Ты злишься, но надо идти в школу» → саморегуляция → «светофор состояния» → дыхание-пауза → Go/NoGo.

## 6. Отчёт для родителя (еженедельно)
- Что тренировали (3 пункта) и сколько минут.
- Прогресс по 2 навыкам (стрелка ↑ / = / ↓) — **без баллов «IQ»**.
- 1 победа ребёнка (формулировка от специалиста, не «оценка»).
- 1 зона роста + что делать дома 10 минут.
- 1 вопрос для обсуждения с ребёнком за ужином.
- Кнопка «рассказать специалиту» (в MVP — свободный текст, в фазе 2 — запись на 20-минутный разбор).

## 7. Техстек
- **Фронт:** Next.js (App Router) + TypeScript, PWA (offline-режим для очереди заданий), Tailwind; внутри — Telegram Mini App (используем их SDK для авторизации, но не полагаемся на них).
- **Бэкенд:** Postgres + Prisma; Redis для очередей/кэша; S3-совместимое хранилище для медиа.
- **Бот:** aiogram 3 (родительский канал: отчёты, оплата, напоминания).
- **Контент:** YAML/Markdown в Git, версионируется; каждый сценарий — карточка с метаданными (навык, компетенция, сложность, возраст, теги, ссылка на источник).
- **Платежи:** ЮKassa (или Тинькофф) — recurring-подписки + СБП; своя подписочная модель, без стора.
- **Аналитика:** собственный event-log без ПД ребёнка (псевдонимизированный id), без cookies и внешних SDK для детей.
- **Деплой:** VPS/облако (или Railway/Hetzner), CI — GitHub Actions, бэкапы БД.

## 8. Бэклог на 3 месяца
- Фаза 2: календарь программы (12-недельные программы по возрастам), «слоты» вместо бесконечной ленты.
- Разбор со специалистом (live, 20 мин, ежемесячно) — в тарифе 9 990 ₽/год.
- B2B: лицензия для школ/центров, назначение на группу, отчёт для педагога.
- Летние/зимние челленджи, «семейные» задания (родитель+ребёнок).
- Версии заданий для 11–13 лет с привязкой к ОГЭ/сочинению/проектам.

## 9. Метрики
**Продукт:** активация (первая тренировка в 24 ч), тренировок в неделю, % завершения недельной программы, время в тренировке, число открытых отчётов родителем.
**Удержание:** D1/D7/D30, month-2 retention, churn, конверсия годовой подписки.
**Деньги:** trial→paid, ARPU, ARPA, LTV, CAC, LTV/CAC, gross margin.
**Качество:** NPS родителя, доля семей с ≥2 офлайн-миссиями в месяц, отток после отчёта vs без.
**Целевые значения на 10-й неделе (см. `strategy.md`, п. 7).**

## 10. Что точно НЕ делаем в MVP
- Генеративный ИИ-чат с детьром.
- Диагностические заявления и обещания «IQ/успеваемость вырастет».
- Рекламу, соцсети внутри, покупки в игре.
- Роликовые/мультфильмы (съёмка дорогая, дети не смотрят в MP4).
- Сбор фото/видео ребёнка, геолокации, точных идентификаторов.
