# Постановка сцен (shotlist) и промпт v2 для арта Alice AI ART

Ноябрь 2026. Статус: движок готов, отрисовки не было. Ревизия `docs/art-prompts.md` по итогам приёмки пилота v2 — отдельным шагом.

## Зачем

Пилот w1 (415+208+208 кадров) доказал стиль, но дал одинаковые кадры: промпт состоял на 80 % из стиля и не содержал постановки (место, действие-глагол, эмоция, ракурс). Ink-файлы — педагогический текст, а не раскадровка. Решение: один раз на сцену развернуть ink в постановочные поля LLM-ом и дальше собирать промпт из них детерминированно.

## Конвейер

```
content/ink/*.ink
  → scripts/art-stage.ts        (Alice AI LLM Flash, ~0,02 ₽/сцена, один раз)
  → data/art-shotlist.json      (черновик постановки; человек правит глазами)
  → ревью: git diff после генерации; needs_review=true — обязательно к осмотру
  → scripts/yandex-art.ts       (Alice AI ART; 4 кандидата = 4 разные камеры)
  → out/art/*.png               (git-ignored)
  → отбор глазами → public/art/v2/ai-pilot-w1/ (или куда решит владелец)
```

## Поля shotlist (на сцену, не на файл — одна постановка на все три линейки)

| поле | смысл |
| --- | --- |
| `location` | одна из канона: дом, комната, класс, двор, площадка, парк, библиотека, рынок, теплица, мастерская, карта района |
| `action` | действие ГЛАГОЛОМ, до 8 слов («присел у пустой полки») |
| `emotion` | 1–2 слова («тихая грусть») |
| `props` | до 3 опорных предметов |
| `video_role` | `start-frame` (поза с потенциалом движения) / `cutaway` (деталь/реакция) |
| `needs_review` | `true`, если LLM не вернул валидный JSON — обязателен осмотр |

Существующие записи не перезаписываются; `--force` перегенерирует всё (при этом ручные правки теряются — только с чистого согласия).

## Промпт v2 (8 слотов)

`стиль-якорь (короткий) → канон героя линейки → Кадр (ротация VARIANTS) → Локация (+props) → Действие/Эмоция → Reels-ограничения (один герой, центр, воздух, без motion blur, без текста)`.

Ротация кандидатов (гарантирует структурное различие, а не «ещё раз тот же»):
1. общий план, вровень, анфас, симметричная композиция;
2. средний план, три четверти, правило третей;
3. крупный план, лёгкий верхний ракурс, правило третей;
4. общий план, лёгкий нижний ракурс, ведущая линия.

`data/art-shotlist.json` коммитится в репозиторий: это арт-постановочный документ, его ревью — git diff.

## Стоимость (по тарифам из docs/yandex-case.md)

| шаг | объём | ≈ расход |
| --- | --- | --- |
| shotlist | 121 уникальная сцена | 25 ₽ |
| тест-отрисовка w1 (3 сцены × 3 линейки × 4 кандидата) | 36 кадров | 80 ₽ |
| полный проход w1–w12 × 1 кадр/сцена | ≈ 360 кадров | ≈ 800 ₽ |
| отбор хвоста/ретраи ×1,5 | — | ≈ 1 200 ₽ суммарно |

Остаток гранта ≈ 7 900 ₽. Сначала тест, потом полный проход — только по факту приёмки теста.

## Команды (на Маке, ключ — только в окружении)

```bash
git pull

# 1) постановка всех сцен (сухой прогон сначала — показывает объём и цену)
npx tsx scripts/art-stage.ts
YANDEX_API_KEY=КЛЮЧ npx tsx scripts/art-stage.ts --yes
# откройте data/art-shotlist.json, поправьте глазами, закоммитьте:
git add data/art-shotlist.json && git commit -m "Shotlist: LLM staging, human review" && git push

# 2) тестовая отрисовка 3 сцен недели 1 (≈80 ₽)
YANDEX_API_KEY=КЛЮЧ npx tsx scripts/yandex-art.ts --only=w1d1 --candidates=4 --yes

# 3) Reels-пропорции: сначала ОДНИМ кадром проверить, что API принимает размер
YANDEX_ART_SIZE=1024x1792 YANDEX_API_KEY=КЛЮЧ npx tsx scripts/yandex-art.ts \
  --only=w1d1 --band=8-10 --candidates=1 --limit=1 --yes
# если 400/invalid_request_error — вернуться на 1024x1024 и кропать в монтаже (assylum: blur-pad)
```

## Ограничения и открытые вопросы

- Размер 1024×1792 не проверен API Alice AI ART — проверка на 1 кадре обязательна до любой серийной траты.
- image→video (AI Studio) требует: один герой, неперекрытые конечности, «поза с потенциалом движения», без текста — всё это зашито в Reels-слот промпта; дополнительная проверка — глазами на тесте.
- Согласованность лица героя между кадрами держится только канон-строкой (дообучение изображениями в API нет) — принимается как свойство стиля.
- Стрелы/вопросительность ink-текста в промпт не попадают: действием владеет shotlist.
