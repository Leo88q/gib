# Графика: стиль и промпты

## Стиль (текущий)

Единый визуальный язык — **мультяшный сериал 90-х**: толстые чёрные контуры, плоская
cel-заливка, насыщенные цвета, комичные пропорции, большие выразительные глаза.

Базовый хвост промпта:
`Retro 1990s cartoon animation style ..., thick black outlines, flat cel-shaded saturated colors, simple shapes, comedic proportions, centered composition, plain white background, no text, no letters, no watermark`

Персонажи и локации рисуются как **собственные** (лисёнок-маскот «Лис», дети) —
никаких копий чужих мультсериалов.

## Иконки и сцены программы

### Иконки компетенций (7, готовы) — хвост `... icon:`
1. `icon-self-awareness` — ребёнок перед зеркалом, вокруг разноцветные кружки эмоций.
2. `icon-self-regulation` — ребёнок делает вдох, мягкие голубые волны, зелёный светофор.
3. `icon-empathy` — один ребёнок утешает другого, между ними маленькое сердце.
4. `icon-relationships` — дети держат палец обещанием, над ними облачка реплик.
5. `icon-decision-making` — развилка дороги с двумя стрелками, думающий ребёнок в центре.
6. `icon-creative-thinking` — жёлтая лампочка, звёзды, искры, кисточка.
7. `icon-growth-mindset` — росток из раскрытой книги, ступеньки вверх, солнце.

## После генерации
```bash
npm run optimize:art   # ресайз 512px + PNG8: 12 МБ → ~0.5 МБ
npm run check:art      # проверить манифест
npm run check:art -- --strict  # код ошибки, пока отсутствует хоть один файл
```


Иконки семи компетенций и иллюстрации всех 12 недель — оригинальные AI-изображения, подготовленные для проекта. Путь к каждой картинке навыка и компетенции задаётся в `lib/art-paths.ts`, автоматическая проверка доступных файлов — `npm run test:art-paths`. Проверка в Telegram WebView ещё не проводилась.
