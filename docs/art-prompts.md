# Графика: стиль и промпты

## Коротко

Единый визуальный язык — **«мягкий объём»**: 3D, фетр и плюш, пастель, студийный свет сверху-слева.
Полные правила (материал, свет, пропорции, позы, палитра, чек-лист приёмки) — в
[`design/style-passport.md`](../design/style-passport.md). Этот файл — прикладная часть:
что уже лежит в `public/art`, что и как генерировать дальше.

## Стиль (текущий)

Базовый хвост промпта:

```
Soft 3D render, felt and plush materials, chunky rounded shapes, matte surfaces,
one soft studio light from upper left, warm palette (oatmeal, terracotta, muted mint,
dusty indigo, one amber glow), plain warm cream background (#FDF4E9),
no text, no letters, no logos, no watermark
```

Правила, без которых картинка «выпадает» из серии:

- **без текста в картинке** — ни букв, ни цифр, ни логотипов: подписи ставит код;
- **один источник света** сверху-слева и мягкая контактная тень;
- **один акцент на картинку**; герои цветные, предметы и существа — тёплые нейтральные;
- **референс-картинка при генерации обязательна**, иначе уезжают материал и свет.

## Новая партия: `public/art/v2` (перенесена в приложение)

Сделано в концепте (`design/3d/`, кропы — `design/preview/img/`):

| Что | Файлы | Размер |
|---|---|---|
| Проводники | `creatures/lis`, `mira`, `tima` | 3:4, альфа |
| Существа навыков (6) | внимание, память, гибкость, торможение, планирование, логика | 3:4, альфа |
| Питомец (1) | младшая стадия; средняя и взрослая — к отрисовке | 3:4, альфа |
| Предметы (19) | гардероб 9, комната 4, упражнения 6 | 1:1, альфа |
| Места (7 + карта) | дом, двор, библиотека, площадка, рынок, теплица, мастерская | 16:9, без альфы |

Партия уже подключена к коду: `lib/art-paths.ts` отдаёт существа навыков вместо иконок,
места района вместо сцен недель, `npm run check:art` проверяет 37 файлов `v2`,
`npm run test:art-paths` — что каждый путь существует и является настоящим PNG.

Чего в новой партии ещё нет: альфа-вырезки у предметов и героев (фон бумажный, поэтому
в маленьких слотах картинка обрезается по лицу), поз кроме «стоит», двух старших стадий
питомца, единой серии отрисовки существ (свет и фон у них пока разнятся).

## Как генерировать лист предметов

1. Один кадр на 4–9 объектов: одинаковый свет, одна бумага, одинаковый масштаб.
2. Промпт перечисляет предметы по порядку сетки и требует «even spacing, same scale,
   each object centered in its cell».
3. Нарезка — **по границам предмета** (fuzz 6–7 %) плюс 6 px воздуха, затем вписать в квадрат
   600×600 на цвете бумаги и сохранить в PNG8 без дизеринга.
4. Не резать ровной сеткой: предметы на листе стоят со сдвигом, клетка срезает шапку
   или тянет обрезок соседа (так испортились наушники, корона и шарф в первой попытке).

## После генерации

```bash
npm run optimize:art      # ресайз 512px + PNG8: 12 МБ → ~0.5 МБ
npm run check:art         # проверить набор public/art
npm run check:art -- --strict   # код ошибки, пока отсутствует хоть один файл
```

`check:art` проверяет партию `v2`: 10 персонажей, 19 предметов и 8 сцен (`places` + карта).
Старые 30 PNG в `public/art` остаются на диске до конца переноса экранов и в проверку
больше не входят.

Пути к картинкам навыков и компетенций задаются в `lib/art-paths.ts`; проверка доступных
файлов — `npm run test:art-paths`. Проверка в Telegram WebView ещё не проводилась.
