# Арт-пилот недели 1 (Alice AI ART) — решения и отбор

Статус: рабочий документ. Ноябрь 2026.
Цель пилота — проверить, может ли генеративная модель (Yandex AI Studio, `aliceai-image-art-3.0`)
производить кадры в едином стиле проекта с каноничными героями по возрастам, в объёме «недели 1»
(60-недельная программа, сцены `w1dN*_band`), без доработки руками.

## Состав пилота

Всего в `out/art/` (локально, в git не хранится) ≈ 623 кадра, 1024×1024:

| --- | --- | --- | --- |

## Баги по ходу пилота и их фиксы (все в `scripts/yandex-art.ts`)

1. **Герой был захардкожен в стиле** («…персонаж Лис…») → все кадры выходили лисами.
   Исправлено: стиль не называет героя, герой подмешивается по линейке (`HERO_BY_BAND`) — коммит `79aa8ec`.
2. **Мёртвое регулярное выражение** `(\d-\d+)` не совпадало с `11-13` → линейка 11–13 молча не генерировалась
   (в первом пилоте её не было вовсе). Исправлено на `(\d+-\d+)` — коммит `e4eb4ec`.
3. **Модерация YandexART (400 `invalid_request_error`)** на всех промптах 11–13: слово «подросток».
   Заменено на «мальчик лет одиннадцати-тринадцати» — коммит `a7531ca`; после этого 208/208 без ошибок.
4. Добавлен флаг `--band=5-7|8-10|11-13` для точечной пересъёмки — коммит `bbda700`.

Также: контент-ревью (452 строки) показало один класс ложных отказов модерации — софт-фикс в системном
промпте скрипта ревью — коммит `9146f04`.

## Решения (ноябрь 2026, владелец проекта)

1. **Стиль «мягкий объём» 3D принят** как единый для w1 (вердикт по контактным листам трёх линеек):
   тёплый персиковый фон, мягкий студийный свет, пропорции ~4 головы, большие выразительные глаза.
   Водяная «книжная» акварель не используется.
2. **Перенос в репозиторий — только отобранные кадры**, каталог `public/art/v2/ai-pilot-w1/`.
   Сборка, экраны и UI не меняются: пилот — материал для методиста, не релиз.
   Ни один кадр не уходит в сборку без отдельного решения и «сливай».
3. Кадр `w1d4-5-7#1` не доснимаем.
4. **Отбор — в полном размере, на машине владельца**; ассистент плиток размером ~50 px не «видел» —
   финальное слово всегда за глазами человека. Критерии — `docs/art-direction.md` §4
   (канон героя, читаемость, эмоция, отсутствие текста в кадре, безопасность).
