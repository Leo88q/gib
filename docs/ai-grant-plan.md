# Как потратить грант 10 000 ₽ Yandex AI Studio с максимальной пользой (план)

Цель: получить максимум **полезных артефактов и доказательной базы для запроса большего бюджета у Яндекса**, а не «сжечь» сумму. Недооценённый остаток — не провал: в кейсе важны цифры стоимости и результат, а не нулевой баланс. Дополнительно: всё потраченное конвертируется в то, что видно и слышно ребёнку — голос и картинки.

Данные по корпусу (замер 17.11.2026): 452 ink-файла, ≈326 тыс. произносимых символов, 180 основных сцен + альтернативы × 3 возраста.

## Этап A. Озвучка всей программы — `scripts/yandex-tts.ts`

- Что: все уникальные произносимые реплики корпуса → mp3 в `out/audio/tts/` + `out/tts-manifest.json`.
- Объём: ≈326 тыс. знаков; уникальных реплик будет меньше (много повторов).
- Цена: ≈210–425 ₽ из 10 000.
- Польза: озвучка для 5–7 лет и слабовидящих; боевой сигнал «готовим запуск», а не «прототип в тексте».
- Команда: `YANDEX_API_KEY=... npx tsx scripts/yandex-tts.ts --yes` (без --yes — сухой расчёт, ничего не тратится).

## Этап B. Иллюстрации сцен — `scripts/yandex-art.ts`

- Что: сцены программы; кандидаты на сцену (`--candidates=4`), всё в `out/art/` (не в репозиторий).
- Сначала **неделя 1**: `--only=w1 --candidates=4` → все ink-сцены `w1*` во всех папках редакций (week-one, deep, remaining): 104 сцены × 4 ≈ 416 генераций ≈ 930 ₽.
- Отбор глазами (человеком): считаем «годные кадры» — это цифра для кейса.
- Затем вся программа: 264 сцены (88 сюжетных ячеек × 3 возраста) × 4 кандидата ≈ 1 056 генераций ≈ 2 355 ₽.
- Команда: `YANDEX_API_KEY=... npx tsx scripts/yandex-art.ts --yes --only=w1 --candidates=4`.
- Если Images API отвечает 400/404: взять точный `model`-URI из AI Studio → Playground → «Код» и передать `YANDEX_ART_MODEL=...`.

## Этап C. Ревью корпуса моделью — `scripts/yandex-content-review.ts`

- Что: Alice AI LLM Flash прогоняет каждую историю: сложность чтения, теги навыков, флаг «опасно/требует проверки».
- Выход: `out/content-review.csv` — рабочий документ для методиста. Файлы ink НЕ изменяются.
- Объём: ≈0,5–1,5 млн токенов ≈ 300–800 ₽.
- Команда: `YANDEX_API_KEY=... npx tsx scripts/yandex-content-review.ts --yes --only=week-one`.

## Этап D. Усиление доказательной базы (опция, на остаток)

- Дополнительные кандидаты на лучшие сцены (отбраковка/варианты) — по 2–3 перегенерации каждой сильной сцены: +500–1 500 ₽.
- Баннеры 12 недель (6 вариантов каждый): ~72 генерации ≈ 160 ₽.
- «Карточки концовок» для механики «Дубль» (после утверждения концепции): ~360 генераций ≈ 800 ₽.
- Эмбеддинги корпуса для семантического поиска (копейки).

## Итоговая экономика (для кейса Яндексу)

| Артефакт | Знаков/штук | Цена |
|---|---|---|
| Озвучка всего корпуса | ≈326 тыс. символов | ≤ 500 ₽ |
| Отбор арта (неделя 1) | ~180 генераций | ≈ 400 ₽ |
| Арт всей программы | ~1 056 генераций | ≈ 2 355 ₽ |
| Ревью корпуса | ~0,5–1,5 млн токенов | ≈ 300–800 ₽ |
| Полные итерации (этапы A–D) | — | ≈ 5 000–8 000 ₽ |

Остаток **не дожимаем насильно**: он остаётся буфером на итерации и перегенерацию — самое полезное для качества. В кейсе честно пишем: «потрачено X ₽, из них Y на озвучку, Z на арт, W на ревью; N% кадров отбраковано».

## Как это превращается в письмо Яндексу

1. Цифры из `out/ai-grant-spend.jsonl` (скрипты дописывают сами): инструмент, объём, оценка стоимости.
2. До/после: экраны «было текст → стало голос+иллюстрация» (пара кадров из `out/art`, отобранных в `public/art`).
3. Кейс — `docs/yandex-case.md`: социальный эффект, честные цифры продукта, что просим и что готовы дать взамен.
4. Письмо: запрос на продолжение гранта до запуска (июнь–сент 2026) + покрытие Managed PostgreSQL / Compute (грант, вероятно, только AI — проверить в Billing).

## Ограничения и честность

- Скрипты не обращаются в сеть без `--yes`; без ключа ничего не тратится.
- mp3 и кандидаты в арт — вне репозитория (`out/`); в git попадают только отобранные финалы.
- Сгенерированный материал — внутренний черновик до проверки человеком; публикуется только после решения владельца/методиста.
- Журнал расходов не содержит секретов и персональных данных.
