# Прототип: что собрано и как запустить

## Запуск

```bash
npm install
GIB_DEMO_MODE=1 npm run dev  # только локально, фиктивные данные
npm run test:engine  # проверки адаптивного движка
npm run typecheck
```

Локально без Telegram приложение тоже работает: профиль создаётся для «локального» родителя.
Чтобы открыть как Mini App: нужен бот (@BotFather → `/newapp` → URL веб-приложения) и, в идеале, HTTPS-туннель.

## Игра

Полноценная игровая механика вместо «текста с кнопками»: XP и 8 уровней, комбо, звёзды за день, 3 миссии дня, 25 значков, комната в SVG, растущий питомец, гардероб за игровые монетки, испытание района в 5-й день недели, звук на WebAudio, конфетти. Подробно — в [`game-design.md`](game-design.md).

Модули: `lib/gamification.ts` (уровни, миссии, значки, гардероб), `lib/engine/rewards.ts` (начисление), `app/api/player/route.ts` (состояние, покупки, миссии), `components/avatarParts.tsx`, `components/Pet.tsx`, `components/Room.tsx`.

## Программа

12 недель × 5 дней = 60 дней, реализовано в `lib/content/program/`. Дни открываются последовательно, сложность заданий адаптивная. Подробности — в [`program.md`](program.md).

## Что уже работает

**Ребёнок (`/`)**
- Онбординг: имя (ник) + возраст. Больше никаких данных не собирается.
- Домашний экран: неделя и день программы, план дня (3 задания + 1 жизненная ситуация), серия дней, кнопка повтора предыдущего дня.
- Тренировка: 4 шага — два когнитивных задания, сценарий мягкого навыка, третье задание.
- 8 когнитивных заданий: Stroop («Цвет слова»), Corsi-сетка («Запомни и повтори»), цифровой ряд, поиск отличий, смена правила, go/no-go, порядок действий, счёт и логика.
- 12 сценариев мягких навыков в трёх возрастных вариантах: самопознание, саморегуляция, эмпатия, отношения, ответственные решения, творческое мышление, мышление роста.
- Адаптивная сложность: лестница по двум верным/неверным подряд, оценка способности по навыку, потолок сложности по возрасту.
- Обратная связь после каждого шага (для сценария — разбор выбранного варианта и «лучший» вариант).

**Родитель (`/parent?profileId=…`)**
- Программа: 12 недель с отметками пройденного, целями для родителя, идеями для дома и вопросом по итогам недели.
- Недельный отчёт: минуты, тренировки, задания, ситуации; динамика по шести навыкам (сравнение с прошлой неделей); победа недели; зона роста; задание на дом; вопрос за ужином; что тренировали в мягких навыках.
- Подписка: тарифы 599 / 4 990 / 9 990 ₽, демо-активация.

**Telegram**
- `POST /api/telegram/report` — собирает текст отчёта и отправляет его через Bot API, если заданы `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`; без них возвращает готовый текст (его же использует бот в ответе на сообщение).

## Архитектура

```
app/
  page.tsx                    клиент: онбординг → дом → тренировка → итоги
  parent/page.tsx             кабинет родителя: отчёт + подписка
  api/profile                 профиль ребёнка (по id родителя)
  api/session                 start/answer + план дня + серия дней
  api/report                  недельный отчёт
  api/subscribe               тарифы и демо-оплата
  api/telegram/report         текст/отправка отчёта в Telegram
lib/
  content/cognitive.ts        8 заданий: генераторы + ключи ответов
  content/softskills.ts       12 базовых сценариев × 3 возрастные линейки
  content/program/            программа: 12 недель, 60 дней, 60 сценариев × 3 линейки
  content/plans.ts            тарифы
  engine/adaptive.ts          лестница, способность, потолок по возрасту, ротация
  engine/session.ts           сборка плана, проведение тренировки, отчёт
  store.ts                    хранилище (JSON-файл; в проде — Postgres)
  types.ts                    типы домена
```

Ключевые решения реализации:
- **Ответы проверяет сервер.** Ключ ответа не покидает сервер: клиент получает задание без флага «правильный», проверка — в `answerStep`.
- **Уровень сложности и оценка способности — в профиле навыка**, поэтому сложность адаптируется между тренировками, а не только внутри.
- **Содержание отчёта не выдумано**: победа недели считается по фактической точности, зона роста и домашнее задание берутся из сценария, который ребёнок разобрал на этой неделе.
- **Хранилище — JSON-файл** (`data/db.json`, в `.gitignore`). Замена на Postgres — одна точка (`lib/store.ts`).
