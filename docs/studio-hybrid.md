# Гибридная 3D-студия «Занавес»: Злата в эфире + персонажи-эталоны

Статус: решения владельца приняты (сет — оба кандидата + сравнение рендером; конвертация — TripoSR на Mac, 0 ₽; пилот — варианты V1 и V2). **Ничего не скачано и не потрачено; скачивания делает владелец на своём Mac** — из sandbox itch.io / CGTrader / Hugging Face недоступны (проверено: все таймауты).

## Решённые вопросы (со слов владельца)

- Формат: гибрид — живая Злата на хромакее → композитинг в готовый 3D-сет.
- Персонажи Лис / Мира / Тима: из наших ART-стилей в **один постоянный 3D-эталон** на каждого — закрывает перегенерацию.
- Показ: комбинированный (студия + вставки окон со слайдами).
- Формат «как прямой эфир» — эстетика, не реальная трансляция.
- Бюджет на студию/3D: **7 000 ₽**.
- Эпизоды должны быть **разными вариантами**, не один шаблон на все 48 выпусков.

## Эталоны персонажей → 3D (TripoSR, Mac)

Шаг 1 (6,7 ₽, требует нового YANDEX_API_KEY на маке):

```bash
python3 -c "import sys" # не нужен; нужен Node 18+ и зависимости репо
node --experimental-strip-types scripts/studio-ref-art.ts            # сухой прогон, 0 ₽
YANDEX_API_KEY=... node --experimental-strip-types scripts/studio-ref-art.ts --yes
# → out/studio-3d/ref-lis.png, ref-mira.png, ref-tima.png
```

Уже после генерации: глазами проверить «анфас, во весь рост, руки не скрещены, лицо читается» — от этого зависит качество меша.

Шаг 2 (0 ₽, на MacBook Pro M4 Pro):

```bash
git clone https://github.com/VAST-AI-Research/TripoSR ~/TripoSR
cd ~/TripoSR && python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt && pip install -e .
# Веса (~2 ГБ) — только на маке (huggingface.co); Type-на-диск любой, лицензия MIT.
triposr --image <ref.png> --output-dir <out> --device mps   # если MPS поддержан; иначе cpu (медленно, ночь — ок)
# или python run.py <ref.png> --output-dir <out>  — см. README репозитория TripoSR на момент установки
```

Шаг 3 (Blender на маке): импорт меш → чистка (decimate/заполнение дыр) → материалы → опционально авто-риг Mixamo (бесплатно) → **один эталон GLB на персонажа** в `design/studio-3d/characters/` (не в git — бинарники; хранить локально, в репо — только ссылка и чеклист).

Оговорки: TripoSR даёт черновой меш (мягкие детали, «запечённый» свет возможен); стилистика Pixar это переживает нормально. Если качество не устроит — следующий шаг за отдельные деньги только по «go»: аренда 24 ГБ NVIDIA (например, Clore.ai, ≈ $0.07–0.21 за час ≈ 6–19 ₽/ч); конвертация троих — это пара часов, реалистично 300–600 ₽ суммарно, через TRELLIS.2 (MIT). Hunyuan3D не использовать.

## Съёмка Златы на хромакее (краткий гайд)

- Полотно/фон: ровный хромакей-зелёный (#00B140 или ткань/краска без складок); дистанция Златы от фона ≥ 1,5 м, чтобы не забэкать зелёный рефлекс.
- Свет: ключ 45° + заполнение с другой стороны (мягкое), контровой сзади сверху (отделяет от фона); фон освещён отдельно и ровно, без горбов.
- Камера: горизонтально, не вкладывать горизонт-чек; минимум 1080p, 25/30 fps; ручной баланс белого.
- Звук: петличка (пушка — для зала), тихое помещение; уровень −12…−6 дБ, без пиков.
- Дубли: каждый склейный кусок в двух дублях; текст — из `*.full.md` (`## Текст озвучки`).
- Композитинг в Resolve (бесплатно): 3D Keyer + Despill, или Blender Compositor (ноды Keying) — сет рендерится с «дырой» под Злату; CorridorKey (open-source, GitHub) — если край волос/движения шумит.
- Титры: «Злата Бабенко», формат серии, дисклеймер канала; кредит 3DLakour, если сет № 1.

## Порядок работ

1. Владелец скачивает оба сета на Mac → кладёт .blend локально (не в git — 240 МБ) → сообщает мне путь/складывает в `design/studio-3d/set/`.
2. Сравнение рендером задней/передней камер (постановка A/B/C/D) → выбираем сет.
3. Владелец запускает `--yes` на эталонные ART (6,7 ₽) → глазная приёмка 3 кадров.
4. TripoSR на Mac → черновые GLB → Blender-чистка → «сердце» эталона застыло (никакой перегенерации дальше).
5. Пилот V2 (без съёмки) → пилот V1 (съёмка Златы) → совместный просмотр → «go» на 48.

## Не делаем без отдельного «go»

- Любые траты сверх ~7 ₽ (аренда GPU), любые покупки сетов, любая публикация.
- Голосовые/TTS-вызовы (отменено решением владельца).
- Правка текстов `*.full.md`; изменение `.gitignore` / коммит .blend/GLB (бинарники).
