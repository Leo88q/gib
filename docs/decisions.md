# Журнал решений (29.10.2026)

## Зафиксировано на встрече

|---|---|---|
| 1 | **Возраст: сразу 5–13, три линейки** (5–7 / 8–10 / 11–13) | Контент пишется в трёх вариантах. Сложность когнитивных заданий ограничена потолком по возрасту. Сценарии мягких навыков имеют отдельный текст для каждой линейки |

| 5 | **Цена 599 ₽/мес** — семейный тариф | Год 4 990 ₽, «год с экспертом» 9 990 ₽ |

## Обновление области интеграций

По решению пользователя GCompris, Kolibri, движок Godot и Yarn Spinner закрыты как ненужные: они не интегрированы и больше не входят в обязательный объём. Это не отменяет проверку лицензий и происхождения уже адаптированного кода из Tilli Godot-Strategies-V1. Решение не изменяет задачи, связанные с ИИ-диалогами и их безопасностью.

## Новые решения по общей игровой логике

Пользователь подтвердил предлагаемую связку и вариант A: единое серверное хранилище, типизированные переходы дня, подбор историй внутри 60-дневной программы, ink-сцены, тематическую практику, семью и долгий прогресс. Чувство можно сохранять **добровольно**; в прототипе оно пока только локальное и не сохраняется. До работы с реальными отметками необходимо определить правовые основания, доступ, срок, отзыв, удаление и защиту, а также пройти экспертную проверку. Отдельный полный план и статус: `docs/unified-game-checklist.md`.

## Как это реализовано в прототипе

| Решение | Где в коде |
|---|---|
| Три возрастные линейки | `lib/types.ts` (`AgeBand`), `lib/engine/adaptive.ts` (`bandOf`, `levelCap`), `lib/content/softskills.ts` (`variants: Record<AgeBand, …>`) |
| Адаптивная сложность | `lib/engine/adaptive.ts`: лестница (2 верных подряд → уровень +1), оценка способности 0..1 с поправкой на скорость, потолок по возрасту |
| Ротация навыков по дням | `pickSkills(..., dayIndex)` — за неделю покрываются все шесть навыков |
| Свой биллинг | `app/api/subscribe/route.ts` + `lib/content/plans.ts` (планы и цены) |
| Отчёт родителю | `lib/engine/session.ts` → `buildReport()`, страница `app/parent/page.tsx`, отправка в Telegram — `app/api/telegram/report/route.ts` |
| Telegram Mini App | `app/layout.tsx` подключает `telegram-web-app.js`, `app/page.tsx` использует `Telegram.WebApp` (haptics, тема) с фолбэком на браузер |

## Сознательно отложено

- Нативные приложения (iOS/Android) — после того как Mini App покажет конверсию.
- Подключение ЮKassa по-настоящему: серверный код проверен только моками, демо-активация удалена; ограничения цифровых платежей каждой платформы требуют проверки.
- Собственный бот Telegram (сейчас есть только API-отправка отчёта; нужен бот с кнопкой «Открыть тренажёр» и еженедельной рассылкой отчёта).
- Живой эксперт (нейропсихолог) и B2B-лицензии для школ/центров.
- Античит: в MVP ключ ответа хранится на сервере, но для заданий «память» и «цифры» стимул равен ответу — при необходимости нужен отдельный серверный протокол.

## Открытые риски, из-за которых решение №4 может понадобиться пересмотреть

1. **Отчёт без специалиста выглядит шаблонно.** Родитель платит за «виденье прогресса» — без живого разбора это слабый аргумент за продление.
2. **Юридический.** Пока продукт позиционируется как «тренажёр», а не как «дополнительное образование», лицензия не нужна. При активной рекламе «программы» и продаже мест в школах — риск переквалификации (см. `strategy.md`, п. 6).
3. **Медицинские формулировки.** В текстах нельзя писать «лечение», «коррекция СДВГ/дислексии», «диагностика». Проверка каждого нового сценария — обязательна.
