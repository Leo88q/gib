# Видео-вебинары: конвейер для всех 48 выпусков

Статус: конвейер собран и проверен локально (дымовой тест обоих форматов); **боевых генераций не было** — кадры ждут явного «go» владельца и нового ключа.

**Решение владельца (2026-11-16): TTS/SpeechKit отменён — Злата Бабенко озвучивает серию сама.** Шаг `webinars:tts` из плана исключён; аудио поставляется готовыми файлами Златы. Яндекс-грант на озвучку не тратится.

Вычитанные тексты (`content/webinars/*/*.full.md`, методистская вычитка завершена) → слайды → живая озвучка (Злата Бабенко) → уникальный кадр ART на слайд (все разные) → mp4 в двух форматах (9:16 и 16:9). Тексты конвейер не переписывает — только снимает markdown-разметку для произношения.

## Что считается финальным (не менять без решения владельца)

- Формат доставки — **видео**; формат кадра — **оба** (9:16 для Reels/MAX, 16:9 для YouTube/сайта).
- Кадры — **все разные, без повторов**: один слайд = один сгенерированный кадр.
- Тексты `.full.md` финальны после вычитки: правки смысла только по явному указанию владельца.
- Публикация — только вручную и по отдельному решению; конвейер ничего никуда не отправляет. Прод-гейты (`launchBlockers()`) не меняются.

## Из чего что берётся

| Шаг | Источник | Выход (в `out/`, в репо не попадает) |
| --- | --- | --- |
| План и смета | `content/webinars/*/…full.md` | `out/webinars/plan.json` |
| Озвучка (TTS) | `## Текст озвучки` → слайды | `out/webinars/audio/<hash>.mp3` + `audio-manifest.json` |
| Кадры (ART) | тема слайда + ротация камеры | `out/webinars/art/<slideId>-c1.png` |
| Сборка (ffmpeg) | кадры + озвучка | `out/webinars/video/<audience>/<slug>.{9x16,16x9}.mp4` |

Разбиение на слайды: абзацы до первого `### ` — слайд «Вступление», дальше каждый заголовок `### ` — один слайд (подпись на кадре = этот заголовок). id слайда детерминирован: `<audience>-<slug>-sNN`, аудио-ключ — `sha1(narration)[:16]` (та же функция, что в `scripts/yandex-tts.ts` и `render-cinema.ts`). Полные дубликаты реплик озвучиваются один раз.

| parent (12) | 207 | 105 982 | — |
| **Всего** | **930** | **673 844** | **≈ 868,07 ₽** (1,3 ₽/1000 симв.) |

- ART: 930 кадров × 2,23 ₽ ≈ **2 073,90 ₽** за 1 кандидата на слайд; 2 кандидата ≈ 4 147,80 ₽.
- Сборка обоих форматов — **0 ₽** (локальный ffmpeg); второй формат бесплатен.
- Озвучка из сметы исключена (решение владельца, 2026-11-16). Итого боевых трат при одном кандидате: **≈ 2 074 ₽** (только ART) поверх уже израсходованных гранта (≈3,5–3,6 тыс ₽ из 10 000).

## Порядок запуска (на маке владельца, после «go»)

```bash
# 0. Предусловия: brew install ffmpeg; НОВЫЙ YANDEX_API_KEY (старый утёк в чат 22.11.2026 — отозвать в Yandex Cloud);
#    teacher .full.md на маке = origin/main.
npm run webinars:plan          # 0 ₽: смета + out/webinars/plan.json
# озвучка НЕ делается через SpeechKit (решение владельца): Злата Бабенко пишет голос сама,
# файлы кладём в out/webinars/audio/<hash>.mp3 до рендера (хэши — из plan.json).
npm run webinars:art           # 0 ₽ сухой прогон
YANDEX_API_KEY=... npm run webinars:art -- --yes   # ≈2 074 ₽, 930 уникальных кадров
npm run webinars:render        # 0 ₽: 9:16 + 16:9 для всех готовых выпусков (голос — файлы Златы)
```

Фильтры: `--audience=teacher|parent`, `--slug=01` (подстрока), `webinars:art -- --candidates=2`, `webinars:render -- --force` (пересобрать сегменты), `--format=9x16|16x9`, `--limit=N`, `--fps=25`. Уже готовые mp3/кадры пропускаются — повторный запуск не тратит деньги.

## Проверено

- `npm run test:webinar-video-plan` (включён в `npm test`): 48 выпусков, 930 слайдов, уникальные id, объём стабилен, markdown/эмодзи в озвучке отсутствуют.
- Дымовой тест полного конвейера на синтетических кадрах/тонах (mac-стиль, linux ffmpeg 9): оба формата собрались, `h264 1080×1920 / 1920×1080` + `aac`, длительность = сумма слайдов, кириллица на кадре рисуется (OpenDyslexic .ttf — первый кандидат для drawtext; если ffmpeg собран без libfreetype, автофолбэк: системный шрифт из fc-list, иначе рендер без текста с печатью причин по каждому шрифту).
- Сборка не стартует, пока чего-то не хватает: сначала все кадры и весь голос, потом рендер (никаких «половинчатых» серий молча).

## Чего конвейер не делает

- Не публикует: загрузка в MAX / YouTube / на сайт — вручную владельцем, после просмотра роликов.
- Не меняет продукт и не открывает релиз: `launchBlockers()` по-прежнему требует реквизиты ИП, ЮKassa, PostgreSQL РФ и внешние шаги РКН/хостинга/TLS/юриста.
- Не переписывает тексты, не трогает `.full.md`, не запускает `expand-webinars --force`.
- Кадры — сгенерированы моделью (Alice AI ART): перед публикацией каждый кадр просматривается глазами; непонравившийся перегенерируется адресно (`--slug=… --force`).

## Замечания по кадрам

Кадры генерятся вертикальными (1024×1792): под 9:16 почти без потерь, под 16:9 — центральный кроп с Ken Burns (мягко, но целостно). Если понадобится нативный горизонтальный арт — отдельное решение владельца (тогда ART ×2, ≈2 756 ₽ при 1 кандидате на формат) и параметр `YANDEX_ART_SIZE=1792x1024`.

Связанное: `docs/cinema.md` (механика Ken Burns и _stills), `SERIES.md` (сетка серии), `docs/art-shotlist.md` (правила «глазами»), журнал трат — `out/ai-grant-spend.jsonl`.

## Разбор ошибок, которые уже встречались

**«Cannot convert argument to a ByteString … 1074»** (или любая > 255) при `webinars:tts` / `webinars:art`: в переменную `YANDEX_API_KEY` попал русский текст, а не ключ — например, копия плейсхолдера из инструкции. Деньги при этом не тратятся: запрос отваливается до отправки. Проверка без печати ключа:
`python3 -c "import os; k=os.environ.get('YANDEX_API_KEY',''); print(len(k), any(ord(c)>127 for c in k))"` → ожидается `False`. Ключ переустановите: `YANDEX_API_KEY=<ключ> npm run webinars:tts -- --yes …` — латиница, цифры, знаки `- _ =`, без пробелов и кавычек-«ёлочек».

**«Ни один шрифт не подошёл для drawtext»**: локальный ffmpeg не смог прожевать ни один шрифт (список с причинами печатается под этим предупреждением). В репозитории лежит проверенный `public/fonts/opendyslexic-regular.ttf` (конвертация woff2 → ttf, кириллица на месте, OFL) — он первый в списке кандидатов; если и он не подошёл, у ffmpeg нет фильтра drawtext (сборка без libfreetype): `brew install ffmpeg`. Запасной режим — рендер без текста на кадре, картинка и голос остаются.

**«Не хватает N файлов — сборка остановлена»**: конвейер сначала требует весь голос и все кадры, потом рендерит — половинчатых серий не бывает, ничего не потрачено (локальный шаг). Сначала `webinars:tts --yes`, потом `webinars:art --yes`, потом `webinars:render`.

**Ролики не появились, хотя команда закончилась**: проверьте пути — выход раскладывается как `out/webinars/video/<audience>/<slug>.{9x16,16x9}.mp4` и сегменты в `out/webinars/video/<audience>/<slug>/<format>/`; `out/` в репозиторий не коммитится.
