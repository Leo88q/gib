# Кинематографичный режим («видео-прохождение»)

Статус: **код готов, роликов пока нет**. Включается флагом `NEXT_PUBLIC_CINEMA_STORY=1`; без роликов продукт ведёт себя ровно как раньше (ScenarioView). Fallback безопасен в обе стороны.

## Что это

Перед каждой сценой истории (неделя × день × линейка) ребёнок видит короткий вертикальный ролик: отобранный кадр пилота, медленное приближение (Ken Burns), закадровый голос alena с первой репликой сцены из ink. По «Вписать choice» ролик заканчивается, поверх кадра проступают варианты ответа — те же, что в обычном режиме. Ответ отправляется в `/api/session` без единого изменения сервера.

## Чего это не делает (и почему)

- **Это не AI-видео «как в GTA VI» на каждый узел диалога.** Такие генераторы нестабильны по лицам и костюмам героев; сотни клипов × 3 линейки вышли бы за остаток гранта и за качество релиза. Путь "настоящее видео" — осознанное решение после релиза и только на показ для недели 1 (см. «Следующий шаг»).
- **Это не блокировка прохождения.** Ребёнок всегда может нажать «Пропустить →»; `prefers-reduced-motion` отключает интро совсем; любой сбой ролика = обычная сцена.
- **Это не изменение механики выборов.** Кино — это презентация сцены; логика вариантов/наград/второго шага не трогается.

## Как собрать ролики из того, что уже есть

1. Отобрать финалисты пилота (см. `docs/art-shotlist.md`) перемещая выбранные кадры в `out/cinema/_stills/<scenarioId>-<band>.png`, например `w1d1-5-7.png`.
2. Озвучку уже должен содержать `out/audio/tts/<hash>.mp3` (сгенерировано ранее: 2 233 реплики). Хэш — от первой реплики ink-файла; скрипт находит mp3 сам.
3. `npx tsx scripts/render-cinema.ts` — вертикальные 1080×1920 ролики с размытым фоном и голосом (ffmpeg, 0 ₽).
4. `npx tsx scripts/build-cinema-manifest.ts` → `public/cinema/manifest.json`.
5. Перенести `out/cinema/<scene>/` в `public/cinema/` (размер кадра ~1–2 МБ × число сцен — коммитим осознанно), `git add public/cinema && git commit`.
6. Включить в конфиге деплоя: `NEXT_PUBLIC_CINEMA_STORY=1`.

## Стоимость

| вариант | цена |
| --- | --- |
| Ken Burns + существующий TTS (релевантные сцены) | ≈ 0 ₽ |
| AI-видео для флагманской недели 1 (≈ 45 клипов) | ≈ 200–350 ₽ при ~4.5–8 ₽/клип [проверить тариф AI Studio video] |
| Полный AI-видеоряд, если когда-нибудь захотим | тысячные рубли и недели постобработки — не сейчас |

## Следующий шаг (после релиза, по решению владельца)

Один «показательный день» в настоящем AI-видео (неделя 1, день 1, три линейки): генератор Yandex AI Studio video или монтаж (CapCut/Premiere) из пилота + TTS + титров; CRM-демонстрация для родителей и Яндекса. Дорого, шумно, выгодно для решения «купить» — но только как один витринный артефакт, не как корпус.

## Честная оговорка про релиз

Кино — это упаковка. Релизный чек-лист не зависит от него: методическая вычитка 8–13, полный арт-прогон, отбор кадров, письмо в Яндекс, «сливай» для мержа. Если что-то из этого не сделано — какую бы красивую сцену мы ни сделали, релиз не готов.
