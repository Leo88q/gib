# Игровой дизайн: «Район Лис»

Продукт перестроен из «тренажёра с текстом» в **игру с историей**: ребёнок не «решает задания», а живёт в городе, который открывается его подвигами.

## Метафора

Мир приложения — **район**, в котором 12 домов (по одному на неделю программы). Ребёнок — герой, у него есть **комната** (она растёт), **питомец** (растёт с уровнем), **гардероб** и **коллекция значков**. Маскот **Лис** — проводник: он даёт квест, хвалит, подсказывает и торопит.

Каждый день программы = **миссия** в текущем районе: 3 когнитивных задания + жизненная ситуация, а в 5-й день недели — **испытание района** (босс: 5 шагов, отдельный баннер, бонусные 50 XP).

## Игровой цикл

```
онбординг → комната (маскот, уровень, миссии дня)
   → [▶ Начать миссию] → квест от маскота → задание → комбо/звёздная пыль
   → ситуация из жизни → экран итогов (звёзды, XP, монетки, значки, конфетти)
   → комната: задачи дня закрыты, монетки тратятся в гардеробе
   → завтра: новые миссии, серия дней растёт
```

## Механики

| Механика | Как работает | Зачем |
|---|---|---|
| **Опыт и уровни** | 8 уровней со званиями: Новичок → Ученик → Исследователь → Умница → Знаток → Стратег → Мастер мысли → Легенда района. XP: 12 за верное задание, 25 за лучший выбор в ситуации, 30 за завершение дня, +40 за идеальный день, +50 за испытание | долгий прогресс, видно рост |
| **Комбо** | Серия верных ответов; каждый шаг сверх первого даёт +2 XP. В интерфейсе — счётчик «⚡ ×N» | удержание внимания внутри миссии |
| **Монетки** | За верные ответы, идеальный день и выполненные миссии | валюта гардероба |
| **Звёзды за день** | 1 — день пройден, 2 — хороший день, 3 — идеальный (все задания без ошибок + лучший выбор) | понятная метрика качества |
| **Миссии дня** | 3 детерминированные на день: «Серия ×5», «Без промахов», «Помощь другу», «Разминка», «Две звезды»; в 5-й день недели — «Испытание дня», раз в 7 дней — «Идеальный день». Награда 35 XP + 15 монет, забирается один раз | причина вернуться завтра |
| **Значки** | 25 штук: за серию, идеальные дни, комбо, каждый закрытый район (12), достижения в 100/500 заданий, все навыки выше 50% | долгосрочная коллекция |
| **Комната** | SVG-сцена: окно, полка с книгами, ковёр, лампа, постер, цветок — появляются за покупки | ощущение «моего места» |
| **Питомец** | Котёнок или дракончик, растёт в 3 стадии по уровню | эмоциональная привязка |
| **Гардероб** | 15 предметов (кепка, наушники, корона, шарф, суперкостюм, рюкзак, питомцы, декор комнаты) за игровые монетки | безопасная экономика без платежей детям |
| **Серия дней** | Считается по календарю, рекорд сохраняется, есть значки за 3/7/21 день | возврат в продукт |

## Регуляторика (важно)

- **Ребёнок не тратит реальные деньги.** Гардероб покупается только за игровые монетки. Реальные платежи (599 ₽/мес и тарифы) делает родитель — через отдельный кабинет/бота.
- **Нет внутриигровых покупок, лутбоксов и рекламы** — требование ФЗ-323 к детскому контенту и Google Families Policy (если позже выйдем в сторы).
- **Минимум ПД**: имя (ник), возраст, профиль. Профиль создаётся для законного представителя.
- **Возрастная маркировка 0+/6+/12+** (436-ФЗ) — контент подходит всем возрастам, но маркировку проставляем.
- **Звук отключается** (кнопка в HUD), анимации уважают `prefers-reduced-motion`.

## Что дальше (бэклог)

1. **Семейный дуэль** — родитель и ребёнок играют в один день: кто быстрее решит 5 заданий.
2. **Квест от родителя** — родитель записывает 30-секундное задание в Telegram-боте, ребёнок выполняет и получает монетки.
3. **Режим учителя/специалиста** — подбор сложности по группе, отчёт для логопеда.
4. **Сезоны** — 4 «сезона» по 12 недель с общей картой района и накопительными наградами.
5. **PDF-отчёт для школы** — сводка за месяц в формате, который можно показать специалисту.
6. **Голосовые подсказки** — озвучка заданий для 5–7 лет (TTS + собственные аудио).

### Набор поддержки в сценариях

В каждой жизненной ситуации доступна необязательная панель с шестью короткими действиями: пузырьки, спокойное дыхание с радугой, раскраска, поддержка себя, комфортное движение и пауза с водой. Панель не оценивается, ничего не сохраняет и не влияет на баллы; её можно свернуть. Перед отправкой ответа ребёнок может изменить выбор и подумать о последствиях. Это не ветвящаяся история: реакцию и разбор по-прежнему выдаёт существующий движок сценариев.

Большинство механик написаны самостоятельно по мотивам Tilli; алгоритм выбора позиций волн пузырьков адаптирован из кода Tilli (см. ниже). Графика и звук Tilli не переносились. Медицинские эффекты не заявляются. Перед выпуском нужны экспертная проверка, тестирование с детьми и проверка доступности; полноценные разветвлённые истории, озвучка и индивидуальные иллюстрации для каждого занятия остаются отдельной работой.

В набор добавлена оригинальная ветвящаяся история «Секрет в игре»: выбор ведёт к разным сценам, можно вернуться и попробовать другие варианты. Данные и результаты этой истории не отправляются и не влияют на награды. Рекомендация в наборе выбирается по компетенции урока; все занятия доступны в каждом сценарии. Ветка проверяется тестом на существование переходов, достижимость сцен и наличие пути к завершению. Основные 60 сценариев ещё не превращены в многошаговые истории.

В основной истории после выбора доступен необязательный диалог с Лисом: вопрос и несколько реплик зависят от компетенции дня. Он не записывается и не влияет на оценку; перед отправкой основной выбор можно изменить. Это дополнительное размышление, а не индивидуальная ветка последствий для каждого из 180 вариантов. Кнопка чтения вслух использует возможности браузера по запросу пользователя: наличие русского голоса и обработка текста зависят от устройства/провайдера, собственная аудиозапись и микрофон не используются. Нужна проверка в Telegram WebView и оценка приватности конкретных платформ перед выпуском.

Добавлены три самостоятельные ветвящиеся истории: «Рисунок под дождём» (эмоции и поддержка), «Башня для двоих» (границы и договорённости) и «Мост для улитки» (ошибки и обучение). Доступны в каждом SEL-уроке; рекомендованная история зависит от компетенции. Их выборы остаются на устройстве во время открытой истории, без оценки и записи в профиль. Проверка графа историй включена в `npm test`. Они пока не заменяют 60 основных сценариев и не имеют отдельных возрастных редакций; до выпуска необходима редактура специалистом и тестирование с детьми разных возрастов.

«Пузырьковая поляна» дополнена отдельным игровым полем на Phaser 3: движение отключается при системном запросе уменьшить анимацию; альтернативный режим использует обычные доступные кнопки. Мини-игра остаётся необязательной и не сохраняет результаты. Проверка в Telegram и с пользователями ещё необходима.

Для «Пузырьковой поляны» адаптирована логика выбора групп позиций из Tilli Godot-Strategies-V1: волны по 2–4 пузырька (в последней может быть один). В отличие от оригинала волны сменяются без таймера и пузырьки не убегают. Указания об исходном коде и обе найденные лицензии сохранены; проверка прав до запуска остаётся обязательной.
